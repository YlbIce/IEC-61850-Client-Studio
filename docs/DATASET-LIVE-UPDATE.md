# 数据集巡检与仿真联调（Client 0.2.1 / Service 0.3.4）

两端数据集页采用专用左右布局，临时收起工程树与属性栏；切换其他页签恢复原布局。

客户端每秒尝试刷新当前可见的数据集、报告数据集及数据对象读值。慢设备采用单请求链，前次读取未完成不叠加任务；隐藏窗口暂停轮询。展开属性跟随刷新。质量和数据时间来自设备 q/t，缺失则留空，不以采集时间代替。已有报告通知仍保留，但旧报告缓存不再覆盖主动读取快照。一次数据集读取并非全对象跨请求的原子事务；FCDA 单属性成员的 q/t 可能是后续读取。

对象按引用合并展示；dU 直接从设备读取，缺失显示 —。已测标记保留在本机。属性展开包含结构节点及子属性。

服务端点击数据集对象打开运行值/品质编辑，保存后刷新；非标准 value/q/t 点位仍不能通过此数值编辑器修改。自建工程描述现在会创建真正的 DC/dU 属性。

数值仿真页双击非控制点位配置常量/正弦/斜坡/方波、基准、幅值和周期。配置适用于自建工程和导入 CFG/SCL 模型中识别出的标准点位，保存到工程 simulation_overrides 并在加载时恢复。没有有效波形时不再假装运行。SPC/DPC 控制输出不自动仿真。

验证：78 项客户端 C++ 测试；26 项服务端 Node 测试；真实 Electron + MMS 联调（值 237.5、Test 质量 4096、dU、属性展开、自动刷新）；服务端真实 UI 编辑与导入 CFG 仿真恢复；亮暗主题截图。
