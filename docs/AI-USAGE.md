# AI 报文助手（0.3.0）

在独立“报文抓取与分析”窗口，使用工具栏 **AI 学习 / 诊断** 或菜单 **AI 助手**。快捷键 Ctrl+J；报文右键可解释或跟踪交互，协议字段双击可带入问题。

## 配置 DeepSeek

选择“AI 设置”，填写 API Key 并保存。Key 使用 Electron safeStorage / Windows DPAPI 加密，保存到当前 Windows 用户的应用数据目录 `capture-ai.json`。对话框显示实际文件位置；已保存 Key 不回显。留空保存保留原 Key，清除按钮删除本地配置。系统加密不可用时拒绝保存，不回退明文。

默认模型 `deepseek-flash`，仅使用官方 `https://api.deepseek.com/chat/completions`。模型名可手动更新。保存不会上传报文。“测试已保存 Key”会发送固定测试问题，消耗少量 API 额度，不包含抓包内容。

## 学习与诊断

- 四套离线基础课程和客观练习：MMS Read、TCP ACK、分段重组、报告机制。无需 Key。
- 解释选中帧、跟踪请求响应、双击字段提问、自然语言检索及读数诊断需要 Key。
- 云端任务须勾选发送范围。会发送问题、知识卡和按需选取的解析字段，可能包含 IP、对象引用、测量值；不发送完整 PCAP、原始帧字节或文件路径元信息。首版没有工程标识去标识化。
- 引用按钮回到捕获帧。引用帧存在性已校验，模型解释仍需工程师核对，不作自动定责。
- 显示过滤建议由用户点击应用，使用原有 TShark 过滤路径；模型不能执行 shell、抓包启停、遥控、定值或回放写入。
- 取消、切换文件或关闭窗口使旧任务失效。报告可导出 Markdown，包含问题、证据帧、限制、模型和 token 用量。

## 增量专题：数据跳变

展开“数据跳变检查”，填写完整 DA 引用，或从选中帧自动取第一个 ST/MX 数值引用；多个数值时应手动核对目标。可填写允许的变化幅度和变化速率。幅度是原始工程值单位，速率是值/秒，使用抓包相对时间，不是 IED 采样间隔。

“本地扫描”无需 Key；“交给 AI 解释跳变”先重新计算再送给模型。空阈值只统计变化，设置阈值后按严格大于判定候选。品质缺失保持未知。不同 TCP 流、FC 和 Read/Report 来源分别比较，避免把不同连接或不同来源混成跳变。

首版最多前 1000 个语义事件、120 个匹配帧，展示最显著的 20 次变化；覆盖不足会明确标记。不转换超出 JavaScript 安全范围的整数，不实现完整突刺、周期异常或量程诊断。报告映射缺失、未完整解码的数据不纳入数值判断。

## 增量专题：断连重连

“本地连接检查”提取最多前 120 帧 SYN/FIN/RST 控制报文，按 TCP 流整理；同流重复 SYN 不当成新连接。同客户端地址、服务端地址和端口出现多个流时，只标为重复连接候选，可能是并发，不能直接称为异常重连。

“AI 断连重连诊断”结合这些证据并按需查询前后 MMS 交互。FIN 可能是正常关闭，RST 不直接证明某方程序缺陷；只看到 SYN/ACK 也不能证明 MMS 关联已成功。首版是有界的线索整理，不是完整 TCP/MMS 超时和重连状态机。

## 验证状态

`npm run test:ai` 验证规则、凭据、接口约束、输出校验和取消；`npm run test:ai-ui` 使用真实 Electron / DPAPI / 原生捕获模块，模拟云端响应，不连接 DeepSeek。

本轮通过全量 19 项单元测试、语法检查、AI 桌面流程及原捕获 UI 回归。真实样例解析到两个有 SYN/SYN-ACK/FIN 的 TCP 流；跳变目标只有一个观察点，正确返回零次变化，没有虚构跳变。规则测试另外覆盖同流变化、跨流隔离、相同时间和阈值。

真实 DeepSeek 的账户、模型、工具调用兼容性与回答质量，待本机配置实际 Key 后继续验证。当前界面截图 `screenshots/ai-panel-test.png` 使用模拟 API 返回，不能当作真实模型效果证据。


## 0.3.1：独立答案窗口与持久化对话历史

AI 回复自动在 1280 × 900 的可缩放独立窗口显示，支持标题、表格、列表、代码块，以及证据跳转、全文复制和 Markdown 导出。侧栏保留提问和重新打开答案入口。

从报文分析窗口的 **AI 助手 → 对话历史** 菜单或侧栏 **对话历史** 按钮打开独立管理窗口。支持按问题、捕获文件和模型搜索、分页浏览、重新打开与逐条删除。删除需确认；运行中的记录需先结束或取消。查看历史无需 Key，不调用 DeepSeek。

每次有效的已授权提问写入独立记录，开始时保存问题和运行状态，每次取证后保存上下文，结束时保存答案或失败/取消状态。记录按用户数据目录下的 `ai-history` 保存，管理窗口底部显示完整路径；重启后仍保留。API Key 不写入历史，历史中的业务数据以本地 JSON 保存。

保存内容包含问题、模式、时间、模型、答案、证据帧、限制、建议、token 用量，以及捕获文件路径/大小/修改时间、选中帧、MMS 端口、扫描参数和实际取证结果。报文上下文是本次 AI 使用的有限解析快照，包含 packet/search/sessions 查询或跳变/连接扫描结果；不复制完整 PCAP，也不保存模型内部推理。原文件删除后仍可查看这些快照。

文件切换或应用重启后的历史答案仍可阅读、复制、导出，但帧号跳转与筛选禁用，以免对应到另一份捕获。旧版本未保存的过去问答无法自动恢复。当前按每次问答归档，不自动将历史内容发送到后续问题中。

验证截图 `screenshots/ai-answer-window-test.png` 和 `screenshots/ai-history-window-test.png` 均来自真实 Electron 窗口，AI 回复使用模拟接口。新增测试覆盖历史落盘与重新读取、证据上下文、搜索、删除、HTML 安全显示、窗口重开及过期证据禁用。


## 0.3.2：长回答与截断恢复

默认生成预算从4096提高至16384 tokens；遇到服务端 `finish_reason=length` 时，使用相同已获取证据，最多自动重试一次，预算32768 tokens并关闭该次思考。重试会产生额外API用量，两次返回的用量合并记录。未完成工具调用不会被执行，也不会把未闭合JSON接到下一次回答后面。

若仍截断或扩大预算请求失败，提取已生成正文作为“未完成草稿”在答案窗口展示并保存历史；明确标记未经完整事实校验，不生成证据跳转或筛选按钮。没有正文时说明模型尚未生成正文，不展示内部推理。单次请求超时120秒，总任务上限6分钟，可随时取消。

回归使用模拟截断响应，验证长答案恢复、累计用量、截断工具拒绝执行、重试失败保留草稿、取消、桌面警示以及草稿与上下文落盘；未调用真实DeepSeek。

接口依据：https://api-docs.deepseek.com/api/create-chat-completion/


## 0.3.3：界面主题

在每个窗口右上角选择亮色、暗色或跟随系统，也可通过原生菜单“视图 → 主题”切换。主题在主窗口、捕获分析、AI答案和历史窗口之间同步，新窗口直接使用当前主题。默认跟随系统；设置保存到用户数据目录的 `appearance.json`，重启恢复。

样式覆盖数据表、选中行、协议树、代码块、提示状态、输入控件与弹窗。`npm run test:theme` 验证四类窗口同步、两种主题、菜单状态、非法参数、新窗口继承以及独立进程重启恢复；通过模拟 nativeTheme 的系统更新事件验证跟随行为，不修改用户的 Windows 外观设置。截图保存在 `screenshots/theme-*.png`。
