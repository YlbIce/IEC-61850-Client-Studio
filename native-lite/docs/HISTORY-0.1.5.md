# 0.1.5 底部历史与链路监视

## 功能

| 页面 | 内容 |
|---|---|
| 变位遥信 | 已采样遥信对象主值变化；首次观察不产生变位，质量/时标变化不冒充主值变位 |
| 选中遥测的历史数据 | 上方所选设备/对象的 MX 历史快照 |
| 选中遥信的历史数据 | 上方所选 ST 对象的历史快照，含首次采样及品质/时标变化 |
| 选中电度的历史数据 | 上方所选整型 actVal 计数对象历史；支持 BCR 主值读取 |
| 链路监视 | 开始连接、成功、失败、主动断开和意外关闭；来自客户端关联状态，不是原始抓包 |
| 通信日志 | 保留原通信、属性变化、测试记录、错误日志以及筛选/导出 |

表格包含装置连接地址、单调序号、对象引用、dU 描述、值、品质、设备时标、本机接收时间、来源、旧值/详情。支持交替底色、拖动列宽、横向滚动、关键字筛选、跟随最新、右键复制多行/引用、Ctrl+C、导出当前筛选页 CSV。清空历史作用于五个历史页，保留通信日志与当前采样基线。

在数据集表、在线模型 DO 或监视页选择对象，会联动三个“选中…历史”页。该页只展示相应类型、相同设备连接地址和相同对象引用，避免不同设备同名对象混在一起。无选择或该类型未采集时显示空表，采样范围说明常驻显示。

## 数据边界

历史从成功的数据集读取、手动读取与监视快照建立，不额外增加 MMS 请求。界面只选中对象并不启动后台读取；希望切换页面后继续采集，需要加入监视。监视保持原来的每秒最多 4 对象、最多 64 对象限制。

值、品质、设备时标和名称完全相同的连续快照合并；首次观察记录基线，只有后续数字量主值变化才标记为变位。请求失败或无法识别主值的行不作为有效采样。计数对象优先根据实际整型 actVal 属性识别，剩余 ST 归遥信、MX 归遥测，不按中文名称猜测；厂商非标准计数建模需另行适配，不把所有计数数据认定为具有电能单位。

[libiec61850 官方文档](https://support.mz-automation.de/doc/libiec61850/c/latest/group__IEC61850__SERVER__DATA__MODEL__ACCESS.html) 将 BCR actVal 说明为 64 位整数属性；本版本按协议类型读取并保留其文本表示，不转换为浮点电量。

五页共用 5000 条有界记录与一个表格代理，达到容量后淘汰最旧记录。基线最多 20000 对象/FC 组合，淘汰后再次出现视为首次观察。历史当前保存在内存，断开后仍可查看，但退出后不保留；需在退出前导出。设备时间保持原始 UTC 展示，接收时间是本机时间，两者不混用。轮询不能保证捕获采样之间每次跳变，不作为 SOE 或设备历史日志读取功能。

链路关闭通知从协议线程排队送回工作线程，再交给界面；主动断开和旧会话回调通过会话代次隔离，重复断连通知去重，不在协议接收回调中访问 UI 或同步请求。

## 验证

11 项 QtTest 用例通过，含真实 loopback MMS 联调；新增测试覆盖首次基线、主值变位、重复合并、设备隔离、计数分类记录、无效采样忽略、重连基线、5000 条上限与 CSV。真实服务操作使 SPCSO1 变化，验证底部变位页与选中遥信页联动，链路页有连接记录。电度历史分类已单元测试，真实厂家 BCR 数据仍需现场验收。

代码分离为 HistoryModel/HistoryFilter（记录与筛选）、HistoryPanel（界面）、table_export（导出），MainWindow 仅接入采样与选择事件。保留原有日志、报告参数、遥控与监视回归测试。
