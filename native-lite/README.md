# IEC 61850 Client Lite 0.1.6

Qt 5.15 Widgets 原生轻量客户端，独立于既有 Electron Client Studio。兼容目标：Windows 7 SP1 x64、4 GB 内存。当前已在开发机验证运行和 MMS 联调；尚未在真实 Windows 7 / 4 GB 机器验收，不能将兼容目标视为已经通过的认证。

0.1.1 统一了深蓝菜单/工具栏、浅色工作区、数据表和参数弹窗样式，加入连接状态标识及清晰的区域标题。样式使用 Qt Fusion、调色板和内置资源，不增加 WebEngine、外部字体、动画或额外运行库。集中维护文件为 `src/studio_style.cpp`。

0.1.2 增加属性变化监视日志、测试成功/失败/未测及失败原因、行背景色、结果筛选和应用图标。旧版本的“已测”保留为“已测待确认”，不会自动判定成功。

0.1.3 将监视页升级为可展开的实时数据表，显示值、q、t、dU、读取状态及最近成功读取时间；日志增加整行交替底色。通信层与界面层分开编译，独立参数弹窗通过信号提交操作。代码规范和职责边界见 [架构说明](docs/ARCHITECTURE.md)。

0.1.4 增加可配置 ISO/ACSE 连接参数、AP-title 不发送选项、10 秒默认连接/请求超时和连接阶段日志。按用户确认的 atc61850/osicfg.xml 提供 `profiles/atc61850-local1.json`，在连接窗口点击“导入连接配置…”使用。此配置只对应该设备，不作为所有 MMS-Lite 设备的通用值。真实设备连接仍需现场验证。

0.1.5 扩展底部分类历史区：变位遥信、选中遥测/遥信/电度历史、链路监视及原通信日志。历史行展示装置、序号、引用、dU、值、品质、设备时标、本机接收时间、来源和旧值；支持关键字筛选、右键复制和 CSV 导出。详见 [历史与链路监视](docs/HISTORY-0.1.5.md)。

0.1.6 将报告采集与页面解耦：已接入报告直接更新对象缓存与历史，界面批量刷新不丢掉批次内变化。连接增加分阶段进度，隔离旧会话断连通知，模型读取失败时保留仍正常的 MMS 关联。详见 [后台报告与连接初始化](docs/BACKGROUND-REPORTS-0.1.6.md)。

## 使用

解压便携包，运行 `Iec61850ClientLite.exe`。无需安装 Qt、Node.js、.NET、抓包驱动或启动另外的通信后台进程。菜单“连接 → 连接 IED”填写地址和端口（默认 102）。

- **数据集**：左侧选择在线数据集，右侧显示对象引用、dU、值、q、设备 t、测试结果和失败原因/备注。默认每秒刷新当前数据集；右键可以读取对象、加入/移除监视、遥控、修改测试结果、复制引用。
- **在线模型**：先读取 LD/LN；展开 LN 时加载 DO。右键 DO 读取主值、质量、时标和 dU，不递归读取全部 DA 的运行值。复杂主值和嵌套子对象按类型结构识别。
- **报告控制块**：双击 BRCB / URCB 设置 RptID、DatSet、BufTm、IntgPd、TrgOps、OptFlds、预留、使能、GI 与缓冲清理。应用后回读真实参数。配置过程中会先停用报告；写失败可能已部分修改，重新读取后再处理。
- **遥控**：自动读取服务端 ctlModel / ctlVal 类型，支持布尔、整数、无符号整数和浮点标量；支持直接控制、SBO 普通/增强安全。SBO 先“选择”，再“执行”。增强安全执行的请求接受不代表最终成功，应查看通信事件中的命令终结 error / addCause。结构型 APC ctlVal 暂不支持，客户端会明确拒绝而不猜测类型。
- **测试记录**：绿色为已测成功、红色为已测失败、白/浅灰为未测、淡黄为旧版已测待确认。标题栏可筛选全部、未测、已测、成功、失败、待确认；双击结果/原因列或右键编辑，失败原因必填（最多 2000 字），保存最新结果、原因/备注、记录时间。清除结果同时清除原因。人工记录不等同于 q.Test；按连接地址、端口、数据集、对象分开保存，刷新、断开和重启不会清除。相同设备使用不同主机名/IP连接时属于不同记录空间。
- **监视与日志**：在线模型或数据集右键加入监视，在“监视对象”页管理。记录主值的叶属性（例如 `mag.f[MX]`）、q、t 和 dU 的旧值→新值、设备时标、电脑记录时间。支持日志类别/关键字筛选、跟随最新、清空、导出当前筛选为 UTF-8 CSV。日志在内存中最多保留 3000 条，满时批量淘汰最旧 500 条；退出前可按需导出。

设置和标记通过 QSettings 保存到当前用户的 `HKEY_CURRENT_USER\Software\IEC61850Studio\ClientLite`。设备时标以 UTC 显示；通信日志使用电脑本地时间。数据缺少 q/t/dU 时显示“—”，不将电脑时间或默认良好质量伪装为设备数据。

## 范围与性能策略

保留在线模型、数据集、报告参数、遥控、已测记录。此版本没有 GOOSE/SV、定值组、报文捕获、AI、文件服务、完整 DA 编辑和历史曲线。

Qt Core/Gui/Widgets + C++17 + libiec61850 静态协议库；不使用 WebEngine、Electron、gRPC/Protobuf。QThread 串行执行 MMS 调用，UI 不等待网络；定时请求不积压，日志最多 3000 条；数据表为 QAbstractTableModel，不为每个单元格创建控件。

监视独立于数据集页面刷新，切换页和打开对话框不会停止。每秒最多轮询 4 个对象，最多 64 个对象，每对象最多 256 个保留属性；网络变慢时整轮耗时会增加。第一次读取仅建立基线，不虚构变化。读取失败时不更新基线并记录错误，恢复后继续比较；非预期断连暂停监视，主动断开或重新连接会清空监视列表。轮询可能漏掉两次采样之间的快速跳变，不作为逐事件 SOE 录波。

报告按成员 inclusion 接收实际变化值，初始化读取成员映射和必要的主值/q/t/dU 基线；FCD 与 FCDA 报告均更新后台缓存。数据集已有有效报告流时，定时刷新读取本地缓存；报告完整覆盖监视对象的 ST/MX 属性时，停止该对象重复轮询。未配置报告、尚未收到报告或覆盖不完整的对象继续按需读取。后台不会擅自启用所有 RCB，也不会抢占其他客户端的报告控制块。建议使能时勾选 GI 建立完整初始报告。

报告回调只复制本次 inclusion 对应数据，不在回调中同步读取。工作线程顺序处理变化，界面每 100 ms 批量接收，历史保留批次内每次不同快照。接收队列、报告映射与界面缓冲均有容量上限，溢出/配置变化会记录缺口并恢复按需读取。报告初始化期间以及不含于报告的 q/t 字段来自最近成功读取值，不能解释成每份报告都带有新时标。dU/类型按连接缓存，重连后重新建立；报告专用对象的 dU 不周期性补读。

切换页面只影响展示与无报告数据集的前台轮询，不停止已接入报告流。历史仍是 5000 条内存快照，退出前需导出；不是具备持久化补传与缺报恢复的 SOE 系统。

## 构建与测试

固定基线：Qt 5.15.2 `mingw81_64`、MinGW 8.1 x64、CMake、Ninja。Windows SDK 目标宏为 `0x0601`，PE 子系统版本 6.1，未启用 AVX 或 GPU 场景渲染。不要用 Qt 6 或新版本工具链直接替换后继续声称兼容 Windows 7。

```powershell
# 在 native-lite 目录运行；可传入实际安装目录。
.\build.ps1 -QtRoot D:\Qt\5.15.2\mingw81_64 -MingwRoot D:\Qt\Tools\mingw810_64
node .\tests\run-integration.js
.\build.ps1 -Package
```

测试脚本仅启动并控制配套 Service Studio 的独立本地服务（127.0.0.1:18274），需要同级 Service Studio 已构建。覆盖模型/数据集/四字段、报告参数及 GI、直接控制、SBO 增强命令终结、原生界面自动刷新和已测持久化/设备隔离。测试使用临时配置目录，不接触用户的已测记录。

便携包输出到 `release/0.1.6`，直接解压运行，避免单文件自解压启动成本。正式交付前须在目标 Win7 SP1 机器验证启动、字体/DPI、连接及断连、具体厂家 RCB/控制行为、大模型与长时间刷新。

## 代码导航

- `src/session.*`：工作线程会话生命周期与命令分发。
- `src/model_reader.cpp`：在线发现、按需读取、字段识别与缓存。
- `src/mms_value.cpp`：MMS 值、质量、时标与引用转换。
- `src/report_service.cpp` / `src/control_service.cpp`：分别负责报告事务与遥控流程。
- `src/point_model.*`：虚拟数据表、已测标记持久化。
- `src/monitor.cpp`：独立轮询监视及属性差异比较。
- `src/event_log.*`：有界日志、筛选和 CSV 导出；`striped_log_view.*` 只负责可见行交替背景。
- `src/monitor_panel.*`：监视快照展示、增量更新和移除操作。
- `src/icons/app.svg`：可编辑矢量图标，`tools/render_icon.cpp` 生成 PNG/ICO；QtSvg 仅生成图标时使用，不随运行包分发。
- `src/main_window.*`：窗口组装、菜单/工具栏与命令调度。
- `src/report_dialog.*`、`control_dialog.*`、`test_result_dialog.*`：独立的报告、遥控和测试结果表单。
- `tests/`：真实 MMS 服务联调及 Qt UI 测试。

扩展数据类型时先按 MMS 类型规格增加主值映射和异常测试，不依赖“结构的第一个元素就是值”。新增协议操作保持在 Session 工作线程，回调只排队通知，不在 libiec61850 接收回调内执行同步请求。

格式检查：`powershell -File tools/check-format.ps1`；自动格式化增加 `-Fix`。只检查本应用源码、测试和工具，不修改第三方协议库。

历史模块：`history_model.*` 管理去重、容量和筛选；`history_panel.*` 负责界面、选中对象联动；`table_export.*` 负责表格 CSV 编码；不把这些职责放进 MainWindow。

`report_pipeline.*` 独立负责报告成员映射、跨线程快照、增量合并和界面批量分发；`Session` 管理连接代次与初始化进度。
